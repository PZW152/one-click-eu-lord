## Key benefits

| Policy | EEA state | What it means for you |
|--------|-----------|-----------------------|
| Edge is uninstallable | `enabled` | You can uninstall Edge |
| Microsoft Store … ability to uninstall | `enabled` | You can uninstall the Microsoft Store |
| User can disable web search | `enabled` | You can turn off web/Bing results in Search |
| Edge is required for web search | `disabled` | Web search is no longer tied to Edge |
| Third party search providers show in search | `enabled` | Third-party search providers can appear |
| First party Widget feed can be disabled | `enabled` | You can turn off the Widgets news and ads feed |
| Full screen user setup promotional surfaces are allowed | `disabled` | No full-screen upsell pages |
| Promotion and direct launch of Edge … from campaigns | `disabled` | No marketing campaigns pushing Edge on you |
| Microsoft Products upsell experiences in Windows Settings via Bing | `disabled` | No upsell offers inside Settings |
| SetAppAsDefault Public API exception for setting Edge as default | `disabled` | In mainland China, Hong Kong, Macao and Taiwan, Edge can no longer make itself the default browser through an API exception |

## Philosophy

The goal is the **superset of benefits**: wherever the EEA grants a *choice* (uninstall, turn off, replace), the tool
makes that choice available to you. It never force-disables a feature on your behalf; whether you actually remove Edge
or Bing is your call. Hardcore mirrors the EEA set **exactly**, because that bundle is Microsoft-defined and internally
consistent, which is more stable and predictable than picking policies one by one.
